# Происхождение данных

`source/social-objects.csv` — предоставленный пользователем архив социальных объектов:
95 записей, 35 столбцов. Два CSV содержат одинаковые записи; три XLSX совпадают между
собой, основные поля сверены с CSV. Исходные значения сохранены в `archiveFields`.

`import-report.json` содержит SHA-256 источника, числа записей и предупреждения.
`geocoding-queries.json` — поисковые запросы по адресам и названиям из архива.
`geocoding-cache.json` — ответы Nominatim; `geocoding-candidates.json` — выбранные кандидаты
с запросом, точностью, ссылкой на OSM и датой. Источник: OpenStreetMap / Nominatim,
[лицензия ODbL](https://www.openstreetmap.org/copyright).

58 исходных пар координат сохранены без изменений в том числе при расхождении АМО.
У 37 объектов координат не было: добавлены приблизительные точки улицы/территории или
населённого пункта. Это НЕ подтверждённое положение здания. У каждой точки стоит
`requiresVerification: true`; исходные пустые координаты доступны в `sourceCoordinates`.
По ним не рассчитывается пешая доступность; совпадения показаны общей точкой со списком.

Особое внимание: archive-007 — исходные координаты не соответствуют заявленному АМО;
archive-089 — Каменка неоднозначна, выбранный Узловский район необходимо подтвердить.
В архиве нет фотографий, оценок жителей и связанного набора контрактов: синтетические
данные второго демо не присвоены реальным объектам.
