# Границы территорий Тульской области

`municipalities.geojson` содержит 26 границ для импорта в `js/data.js`.
Рабочая карта читает их из сформированного набора данных.

- Источник: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
- Лицензия геоданных: [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- Дата получения: 12.09.2026. Это снимок OSM, а не официальное утверждение муниципальных границ.
- API: `https://overpass.kumi.systems/api/interpreter`.
- Состав: 26 отношений административного уровня 6 внутри `RU-TUL`.
- Преобразование: osmtogeojson 3.0.0-beta.5, сохранены Polygon/MultiPolygon,
  координаты округлены до 5 знаков; имена и ID отношений сохранены в properties.
- Цвета декоративные, не кодируют статистику. Для добавленных территорий
  демо-показатели обеспеченности отсутствуют; интерфейс показывает «Нет данных».

Запрос для повторного получения (обновление границ требует проверки изменений):

```overpass
[out:json][timeout:90];
area["ISO3166-2"="RU-TUL"]->.a;
rel(area.a)["boundary"="administrative"]["admin_level"="6"];
out geom;
```

Подробная подложка запрашивается только после выбора территории. Она требует интернета:
OpenStreetMap — схема, Esri World Imagery — спутник. При отказе тайлов показано сообщение
с повторной попыткой; локальные границы и демо-объекты остаются доступны.
