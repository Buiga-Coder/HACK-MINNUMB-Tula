# Основное демо

Основа: предоставленный архив `oks71-tula-demo_3.zip`. Реестр заменён данными
социальных объектов, карта использует настоящие границы и подложку.
Запускайте HTTP-сервер из корня репозитория: необходимые ресурсы находятся также в `../assets/`.
Инструкции, проверки и ограничения: [корневой README](../README.md).
Для обновления данных используйте `python3 tools/import_social_objects.py` из корня репозитория.
