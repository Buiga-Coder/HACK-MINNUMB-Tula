# Карта объектов капитального строительства Тульской области

Основная версия — второе демо `oks71-tula-demo_3.zip`, доработанное в `demo-v2/`.
В каталоге 95 объектов предоставленного архива: 58 с исходными координатами и 37
с приблизительными точками, отмеченными «≈» и «требует проверки».

## Запуск

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://localhost:8000. Сборка не требуется. Границы и Leaflet локальные; подробные тайлы требуют интернета.

При входе видны 26 цветных муниципалитетов на белом фоне. После выбора района
подробная карта отображается внутри его границ, соседи остаются белыми и доступны
для выбора. Настройка «Показать всю карту» включает общую подробную подложку.
По умолчанию показаны 53 введённых объекта; режим «Все» показывает весь архив.
Совпадающие точки объединяются в маркер со списком объектов.

Пешие зоны 5–30 минут — демонстрационное приближение по прямой, 80 м/мин.
Для приблизительных координат этот расчёт отключён. Фотографии, контракты и оценки
не выдумываются: если их нет в архиве, отображается отсутствие данных.
Модельки объектов — условные SVG-значки из второго демо.

Повторный импорт не обращается к сети:

```bash
python3 tools/import_social_objects.py
python3 tests/archive_import_test.py
node --check demo-v2/js/app.js
```

Браузерный тест требует установленного Playwright и Chromium, а также запущенного сайта:

```bash
NODE_PATH=/tmp/tula-map-tools/node_modules node tests/v2-browser.cjs
```

Путь NODE_PATH соответствует текущему компьютеру; на другой машине используйте свою
установку Playwright. Повторный подбор координат: `python3 tools/geocode_missing.py --fetch`,
затем импорт. Запросы последовательные, ответы кэшируются, точки остаются непроверенными.

Полного соответствия ТЗ пока нет: отсутствуют backend, роли, реальные маршруты,
интеграции ПОС/закупок/камер и исходные показатели аналитики. Подробности — в аудите.
