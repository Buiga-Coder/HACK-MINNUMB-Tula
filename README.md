Проект: **Интерактивная карта Тульской области «Объекты капитального строительства, введённые в эксплуатацию»**.

Менторы: Корочкина Ангелина Игорьевна, Холодов Александр Анатольевич.

## Важные условия

- Упомянутое в задании приложение с исходными объектами не предоставлено. Схема данных — проектная; перед импортом необходим маппинг фактических столбцов.
- Карта охватывает введённые объекты и отдельный режим активного строительства, поскольку исходное задание требует оба сценария.
- Не подтверждены API и права доступа к ЕИС, региональным закупкам, ПОС, электронной приёмной, камерам и архивной съёмке. Наличие сайта не означает наличие доступного API.
- Демо, прогнозы, рендеры и неполные данные должны иметь явную маркировку. Переход на внешний сервис не считается отправленным обращением.
- Все шесть функций исходного задания включены в целевой объём. Ограничения MVP не исключают их из промышленной версии.

## Порядок работы

1. Согласовать открытые вопросы и получить исходное приложение.
2. Утвердить методики, поставщиков геоданных и способы интеграции.
3. Реализовать MVP по требованиям с идентификаторами FR/NFR/DATA.
4. Выполнить приёмочные сценарии и оформить протокол.
5. Подключить реальные источники и пройти отдельную приёмку промышленного контура.
